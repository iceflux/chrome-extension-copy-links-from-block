# Copy Links from Block

🌐 [English](README.md) | **Русский**

Расширение для Chrome, которое копирует все ссылки из HTML-блока по правому клику мыши.

## Установка

1. Открой `chrome://extensions/`
2. Включи **Режим разработчика**
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку `chrome_extenshion_copy_links_from_block`

## Использование

1. Наведи курсор на любой блок со ссылками на странице
2. Кликни **правой кнопкой мыши**
3. Выбери **«Копировать ссылки из блока»**
4. Ссылки скопированы в буфер обмена - появится уведомление

Скопированные URL разделены переносом строки - можно вставлять в текстовый редактор, терминал или любой другой инструмент.

## Как это работает

Расширение запоминает элемент, на котором произошёл клик правой кнопкой, затем поднимается по DOM-дереву вверх, пока не найдёт родительский элемент, содержащий **2 и более ссылки**. После этого все `href` из найденного блока собираются и копируются в буфер обмена.

Такой подход не привязан к конкретному CSS-классу или селектору - расширение работает с любой HTML-структурой.
