# Copy Links from Block

🌐 [English](README.md) | **Русский**

Расширение для Chrome, которое копирует все ссылки из HTML-блока по правому клику мыши.

## Установка

1. Открой `chrome://extensions/`
2. Включи **Режим разработчика**
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку `chrome_extenshion_copy_links_from_block`

## Использование

Два способа скопировать ссылки:

### 1. Контекстное меню (всегда работает)

1. Кликни **правой кнопкой мыши** по любому блоку со ссылками
2. Выбери **«Копировать ссылки из блока»**
3. Ссылки скопированы в буфер обмена

### 2. Зажатие клавиши + клик (быстрее)

1. **Зажми** настроенную клавишу (по умолчанию `Alt`)
2. **Наведи** на блок — он подсветится голубой рамкой
3. **Кликни левой кнопкой**, не отпуская клавишу — ссылки скопированы сразу

Клавишу и тему можно изменить в попапе расширения (клик по иконке в панели инструментов).

## Как это работает

Расширение запоминает элемент, на котором произошёл клик правой кнопкой, затем поднимается по DOM-дереву вверх, пока не найдёт родительский элемент, содержащий **2 и более ссылки**. После этого все `href` из найденного блока собираются и копируются в буфер обмена.

Такой подход не привязан к конкретному CSS-классу или селектору — расширение работает с любой HTML-структурой.

Когда зажата настроенная клавиша-модификатор, подсветка показывает целевой блок, а клик копирует ссылки без контекстного меню.
